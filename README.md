\# Smart Quiz Generation and Student Performance Analysis System



\## 📌 Project Overview



Smart Quiz Generation and Student Performance Analysis System is an AI-powered web application designed to help students and teachers create, manage, and analyze quizzes efficiently.



The system uses AI technology to generate quizzes from learning materials and provides performance analysis to identify strengths and improvement areas of students.



\## 🚀 Key Features



\### 👨‍🎓 Student Module

\- Student registration and login

\- View available quizzes

\- Attempt quizzes

\- Automatic result calculation

\- Performance analysis

\- Progress tracking

\- Weak area identification

\- Study planning support



\### 👩‍🏫 Teacher Module

\- Teacher dashboard

\- Upload learning notes

\- Generate quizzes using AI

\- Manage quizzes and questions

\- View student results

\- Analyze student performance

\- Manage learning materials



\### 🔐 Admin Module

\- User management

\- Subject management

\- System reports

\- Settings management



\## 🤖 AI Features



\- AI-based quiz generation

\- Automatic question creation from learning materials

\- Performance analysis and recommendations

\- Learning improvement suggestions

\## ⚙️ Installation Setup



1\. Install XAMPP

2\. Copy project folder into:

xampp/htdocs/





3\. Create MySQL database:

smart\_quiz



4\. Import database file from:

database/smart\_quiz.sql



5\. Update database configuration in:

config/db.php



6\. Run the project:

http://localhost/smart\_quiz\_system/
